# 쿠팡이츠 리뷰 자동 답글

쿠팡이츠 사장님 사이트(store.coupangeats.com)의 리뷰 관리 화면에서 **답글이 없는 리뷰를 찾아 Gemini로 답글을 작성하고 자동 등록**하는 도구입니다.
쿠팡이츠는 사장님용 공개 리뷰 API를 제공하지 않으므로 Playwright로 실제 브라우저를 조작합니다.

## 가장 쉽게 쓰는 법 (관리 화면)

### 처음 한 번만: 설치

압축을 푼 폴더(`coupang_review` 폴더와 `README.md`가 보이는 곳)에서 PowerShell을 열고 차례로 입력하세요.

```
python -m pip install -r requirements.txt
python -m playwright install chromium
python -m coupang_review shortcut
```

마지막 줄을 실행하면 바탕화면에 **"쿠팡이츠 리뷰관리"** 아이콘이 생깁니다.

### 매번: 아이콘 더블클릭

아이콘을 더블클릭하면 크롬에 관리 화면(`http://127.0.0.1:8765`)이 열립니다. 이 화면은 내 컴퓨터에서만 열립니다.

1. **설정**: 가게 이름, 서명, 말투, 리뷰 조회 기간(기본 1주일), Gemini API 키, 자동 등록할 최소 별점을 입력하고 저장합니다. (처음 한 번)
2. **크롬에서 로그인** → 열린 크롬에서 쿠팡이츠에 로그인 → **로그인 완료**. (처음 한 번, 풀렸을 때만)
3. **답글 미리보기**: 미답변 리뷰와 AI 답글이 목록으로 나옵니다. 답글을 직접 고치거나 체크를 풀 수 있습니다.
4. **선택한 답글 등록**: 체크한 답글만 쿠팡이츠에 올립니다. 한 번에 다 올리려면 **전체 자동 등록**을 누르세요.
5. 진행 중에는 **중지**로 멈출 수 있고, **등록 기록** 탭에서 지금까지 단 답글을 볼 수 있습니다.

> 아이콘 없이 열려면 그 폴더에서 `python -m coupang_review`를 입력하세요.
>
> 로그인 때 "해당하는 요청을 처리할 권한이 존재하지 않습니다"(403)가 뜨는 건 쿠팡이츠가 자동화 브라우저를 막기 때문입니다.
> 그래서 이 도구는 컴퓨터에 **설치된 크롬/엣지**를 평범하게 띄워 로그인하게 하고, 로그인이 끝난 뒤에만 연결합니다.
> 도구가 띄운 크롬 창은 작업하는 동안 닫지 마세요.

## 동작 방식

1. 설치된 크롬/엣지를 띄우고 저장된 로그인 정보(`session.json`)로 사장님 사이트에 접속합니다.
2. 리뷰 관리 페이지에서 리뷰를 읽고, 이미 답글이 있거나 이전에 처리한 리뷰(`state.json`)는 건너뜁니다.
3. 기준 별점(기본 3점) 미만인 리뷰는 **자동 등록하지 않고** 사장님이 직접 확인하도록 남겨둡니다.
4. Gemini가 리뷰 내용, 별점, 메뉴를 보고 가게 말투에 맞는 답글을 씁니다. API 키가 없거나 호출이 실패하면 템플릿 답글을 사용합니다.
5. `--post` 옵션을 줄 때만 실제로 등록합니다. 기본값은 dry-run(미리보기)입니다.

## 설치

```bash
pip install -r requirements.txt
playwright install chromium
cp config.example.yaml config.yaml   # 가게 이름, 말투, 서명 등을 수정
# config.yaml 의 reply.api_key 에 Gemini API 키 입력 (https://aistudio.google.com/apikey, 없으면 템플릿 사용)
```

## 명령어로 쓰기 (선택)

```bash
# 1) 최초 1회: 크롬 창에서 직접 로그인 (휴대폰 인증 등 포함). 로그인 정보는 session.json 에 저장됩니다.
python -m coupang_review login

# 2) 미리보기: 답글을 생성해 출력만 합니다 (등록 안 함).
python -m coupang_review run

# 3) 실제 등록
python -m coupang_review run --post
```

- `--headful`을 주면 브라우저 창을 띄워 진행 과정을 볼 수 있습니다.
- 환경변수 `COUPANG_EATS_ID` / `COUPANG_EATS_PW`를 설정하면 세션이 만료됐을 때 자동으로 로그인합니다. 추가 인증이 뜨면 `login` 명령을 다시 실행하세요.
- `run.interval_minutes`를 설정(예: 60)하면 주기적으로 반복 실행합니다. cron으로 `run --post`를 돌려도 됩니다.

## 리뷰를 찾는 방식 (셀렉터 설정 불필요)

기본값인 `site.mode: auto`에서는 사장님 사이트의 HTML 구조를 몰라도 동작합니다.

1. 조회 기간을 설정한 기간(기본 **1주일**)으로 바꿉니다. 관리 화면 설정에서 1주일·1개월·3개월·6개월·1년 중 고를 수 있습니다. 그 버튼이 없으면 그보다 긴 기간 중 가장 짧은 것을 고릅니다. 기간이 드롭다운 안에 있으면 펼쳐서 고르고, "조회" 버튼이 있으면 누릅니다.
2. "미답변" 탭이 있으면 누릅니다.
3. 화면에서 **"사장님 댓글 등록"처럼 생긴 버튼**을 찾아 버튼이 들어 있는 리뷰 카드를 알아냅니다. 답글이 이미 있는 리뷰는 이 버튼이 없어서 자동으로 제외됩니다.
4. Gemini가 카드의 **스크린샷과 글자**를 보고 작성자, 별점(별 개수), 메뉴, 리뷰 내용을 읽습니다. API 키가 없으면 글자만으로 대략 추출합니다.
5. 버튼을 누르면 뜨는 입력창에 답글을 넣고 가장 가까운 "등록" 버튼을 누릅니다. 확인 팝업이 뜨면 "확인"도 누릅니다.

6. 화면의 리뷰를 다 처리하면 "더보기"를 누르거나 스크롤해서 더 불러오고, 다음 페이지로 넘어가며 **끝까지** 처리합니다.

조회 기간은 `site.period`(1주일/1개월/3개월/6개월/1년)로 정하고, 버튼 글자가 아예 다르면 `site.period_texts`에 직접 적으세요. 댓글 버튼 글자가 다르면(예: "답변하기") `config.yaml`의 `site.reply_button_text`를 바꾸세요.
그래도 안 되면 `python -m coupang_review inspect`로 `debug/` 폴더에 페이지를 저장해 확인할 수 있습니다. 이때 `site.mode: selectors`로 바꾸고 CSS 셀렉터를 직접 지정할 수도 있습니다.

## 주의사항

- 자동화 도구 사용은 쿠팡이츠 이용약관에 저촉될 수 있습니다. 본인 매장 계정에서만, 과도하지 않은 빈도(`delay_between_replies_sec`, `max_replies_per_run`)로 사용하세요.
- `config.yaml`, `.chrome-profile/`, `session.json`(로그인 정보), `state.json`은 `.gitignore`에 포함되어 있습니다. 커밋하지 마세요.
- 1~2점 리뷰에는 사장님이 직접 답글을 다는 편이 좋습니다. 필요하면 `min_rating_to_auto_reply`를 1로 낮출 수 있습니다.
